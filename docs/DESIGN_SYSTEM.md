# CarbonRoot Design System

## Creative Direction
CarbonRoot should feel like audited trust with strong editorial control.

The look should be:
- precise
- calm
- premium
- modern

It should not feel like:
- generic SaaS
- loud crypto branding
- eco cliché styling

## Core Visual Rules

### Layout
- Prefer strong whitespace over dense cards
- Use section spacing to create separation instead of constant dividers
- Let major headings breathe

### Surface Logic
- Use background shifts and spacing to separate sections
- Avoid relying on visible 1px borders for every surface
- Keep the page light and transparent rather than dark or glassy by default

### Typography
- Display voice: Manrope
- Body voice: Inter
- Headings should feel editorial and confident
- Labels should feel functional and quiet

## Color Direction
- Mineral greens and deep teals
- Clean warm neutrals
- restrained gold only for verification emphasis

The UI should feel verified and institutional, not playful or overly organic.

## Component Priorities

### Highest Priority
- Hero
- primary CTA buttons
- proof and certificate surfaces
- feature cards
- project highlight surfaces

### Lower Priority
- decorative flourishes
- ornamental icon use
- non-essential motion details

## Motion Rules
Motion should support trust and clarity, not spectacle.

### Phase 1 must-haves
- primary CTA hover treatment
- nav link hover treatment
- hero proof card entrance
- stat count-up on view
- subtle feature card depth
- project image depth treatment

### Phase 2 later polish
- footer interactions
- finer card micro-interactions
- certificate surface embellishments

### Avoid
- noisy headline animation
- heavy cinematic motion
- anything that makes the platform feel gimmicky

## UX Tone By Product Mode

### Compliance Mode
- more structured
- more information-dense
- more operational and report-oriented

### Simple Mode
- more guided
- more visual
- more outcome-oriented

## Copy Rules For UI
- lead with trust and proof
- keep Web3 complexity hidden where possible
- show transaction details where they help proof, not as product theater
- avoid investment language

## Asset Priorities
When choosing what matters most visually:
1. certificate and proof surfaces
2. project imagery
3. trust signals and verification language
4. CTAs
